# Prebuilt libduckdb archives — single source of truth for a version bump.
#
# The `version` line must match what the duckdb crate in Cargo.lock encodes:
# crate 1.MAJOR_MINOR_PATCH.x  <=>  DuckDB vMAJOR.MINOR.PATCH
# (currently libduckdb-sys 1.10505.0 => v1.5.5). fetch-duckdb.sh checks this
# agreement and refuses to run on a mismatch, so bumping the duckdb dependency
# without updating this file fails loudly instead of linking a skew archive.
#
# A version bump is exactly this file's diff: change `version`, replace every
# hash. DuckDB publishes no checksums for these assets, so these are
# self-computed pins (SEC-37/TASK-1663 posture) — verified on first pinning,
# enforced on every fetch thereafter.
version v1.5.5
